# Department pages to save

Save each page into **this folder** (`GC-Course-Catalog/saved-pages/`) so the scraper can read it.

**How to save each one**

1. Click the link. It opens the department's course page in your browser.
2. Press **Ctrl+S**.
3. Set **Save as type** to **Webpage, HTML Only** (not "Complete", which also saves every image).
5. Tick the box.

You don't need to open the dropdowns first: an HTML save keeps the text inside them.
If a page says "Page Not Found", skip it and leave a note next to it.
Psychology isn't listed: the scraper reads its Google Sheet directly.

Tip: take your time between pages. The site starts refusing requests ("Too Many Requests") if pages are opened very quickly.
